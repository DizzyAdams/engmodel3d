# Roadmap

## Fase 1: Fundação

- definir nicho inicial
- escolher stack técnica
- criar viewer 3D mínimo
- criar pipeline de geração paramétrica
- validar exportação de pelo menos um formato

## Fase 2: MVP

- briefing em linguagem natural
- geração de proposta de peça/projeto
- painel de parâmetros
- histórico de versões
- exportação profissional

## Fase 3: Produto sério

- colaboração multiusuário
- bibliotecas de componentes
- regras de engenharia
- auditoria de versões
- integração com projetos reais

## Fase 4: Empresa

- pacote enterprise
- integrações com CAD/BIM
- onboarding para equipes
- suporte e automação customizada

## Decisão de Nicho

Escolher apenas um para começar:

- mecânica leve
- arquitetura/BIM
- mobiliário técnico
- produto industrial configurável
- peças para fabricação digital
